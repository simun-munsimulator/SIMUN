What Is an API Key, and Why Does SIMUN Need One?

SIMUN runs on a bring-your-own-key system. Instead of us charging you for every delegate and chair speech the AI generates on our server, you use your own API key and pay the AI company directly. There's no middleman markup or hidden charges, just the real cost of the AI work your simulation uses, which isn't much.

You may have only used AI through a website or chatbot like Claude, Gemini, or ChatGPT, so an "API key" may sound uncomfortably technical. But getting one is so simple. The videos on the left guide you through it in a few easy steps.

An API key (Application Programming Interface) allows one software to talk to another. SIMUN supports several AI models of varying cost and sophistication. Once you provide SIMUN with your chosen API key, it uses this to to run the AI simulation. The AI model directly charges you for every turn you play on SIMUN. If you use a paid AI model then SIMUN displays the amount you have spent, while if you use a free model like the lowest tier of Gemini, then every turn on SIMUN uses up one of your daily quota of requests.

Like a password, an API key is a string of letters and numbers sk-ant-xxxxxxxx that proves the request, and the bill for it, belongs to you. SIMUN uses your key only to run your simulation. It never stores or shares it. Like any other password, you too should never share it with anyone or post it publicly.

So What Will a Committee Session Actually Cost Me?

AI credits are deducted for each turn during the simulation, but the amount for each turn is tiny and there are many turns per MUN session. So the real question is, how much does it cost to play an entire MUN session right up to the conclusion where the best delegate is announced.

When I tested it out, a full SIMUN committee session run end-to-end on Claude Sonnet 5 came out to about $2 total which is less than Rs. 200.

API billing works like a prepaid phone plan. You load a small amount of credit onto your key, and it ticks down as SIMUN uses the model on your behalf. Providers typically suggest starting with around $5 of credit, which at roughly $2 a session means you can comfortably run a committee two times over, try a different topic, or replay a session with a different approach.

For the price of a Starbucks coffee that vanishes in under thirty minutes, you can enjoy a full day of diplomatic intrigue.

Getting an Anthropic (Claude) API Key

Anthropic is the company behind Claude. Their developer platform is called the Claude Console.

  1. Go to console.anthropic.com and sign up with your email, Google account, or single sign-on.
  2. Once logged in, open the API Keys section from the left-hand menu.
  3. Click Create Key, give it a short descriptive name (e.g. "my project"), and confirm.
  4. Copy the key immediately and store it somewhere safe (for security reasons, Anthropic will only show you the full key once).
  5. Open Plans & Billing and add a payment method, then add a small amount of credit (Anthropic suggests starting around $5) so the key is active and ready to use.
Keys always start with sk-ant-. If you lose a key, you can't recover it, just delete it in the Console and create a new one.

Which Claude Model Should I Use for a Committee Session?

Claude comes in three main tiers. All of them are paid but the price difference between tiers is large, so picking the right one matters a lot for your budget.

Haiku

Cheapest and fastest. Fine for exploring the interface or a throwaway test, but too unspohisticated for a meaningful complete session.

Sonnet

The best value for money. Delegates hold consistent positions, respond meaningfully, and the chair enforces the ROP at a reasonable price of about $2 for the entire committee.

Opus

Capable, witha hefty price tag. Costs 2-3 times more than Sonner. Allows for the sparpest possible debate, but for most practice and learning purposes it's overkill.

A simple rule of thumb: use Haiku only to confirm your key is working, run Sonnet for realistic debate and only reach for Opus if you want the best quality available and have the budget for it.

Getting a Google Gemini API Key

Google's AI models are called Gemini. The only platfrom supported by SIMUN that provides a free key is Google AI Studio.

  1. Go to aistudio.google.com/app/apikey and sign in with your Google account.
  2. Click Create API key.
  3. Choose to create it in a new project (AI Studio will set this up automatically for you) or an existing Google Cloud project if you already have one.
  4. Your key appears on screen — copy it. Unlike Anthropic and OpenAI, Google lets you come back and view the key again later from the AI Studio dashboard if you lose it.
A warning about the free tier. Google offers a free quota, but it is enormously popular worldwide, so you'll regularly encounter a "503 overloadd error" and "429 quota exceeded" errors well before you reach your nominal limit, because failed requests still eat into your daily allowance, meaning the free tier practically amounts to nothing at most times.

Getting an OpenAI (ChatGPT) API Key

OpenAI makes the GPT models behind ChatGPT. Their developer site, the OpenAI Platform, is a completely separate system from ChatGPT.com — so a ChatGPT Plus subscription does not give you API access or credit, and API usage has to be paid for separately.

  1. Go to platform.openai.com and sign in (or sign up) with your email, Google, or Microsoft account.
  2. If this is your first time, OpenAI will ask you to create an "organization" and a "project" — just follow the prompts and accept the defaults if you're not sure.
  3. Open the API keys page, directly at platform.openai.com/api-keys.
  4. Click Create new secret key, name it, and create it.
  5. Copy the key right away — like Anthropic, OpenAI only displays the full key once.
  6. Open Billing in the Platform and add a payment method and some credit if you see an "insufficient quota" error when you try to use the key.
Keys typically start with sk-proj-. Treat it like a password: never paste it into code you publish publicly or share in a chat.

Which OpenAI Model Should I Use for a Committee Session?

OpenAI's current line-up follows a similar "small, medium, large" pattern to Claude's and Gemini's, just with different names.

Nano

Cheapest, fastest. Built for simple, high-volume, low-stakes tasks. Not sufficient for an immersive MUN experience.

Mini

A solid middle ground. Noticeably better reasoning than Nano for a moderate price increase. Good for fun or low-stakes experiments.

Standard

The full-size flagship model (and its slower "thinking" variants, which take a while). Best quality and the best choice for a tough and realistic challenge.

OpenAI renames and re-releases these fairly often (you may see version numbers attached, like GPT-5 or newer), but the nano / mini / full-size pattern — and the price ladder that goes with it — tends to stay the same.

Learn more: platform.openai.com/docs (developer documentation) · platform.openai.com/docs/pricing (current, exact prices)
