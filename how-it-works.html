Step 1: Get An API key

To get an API key to use in this website, do the following:

  1. Open Google AI studios.
  2. Sign in (if required).
  3. Click 'Create New Project'.
  4. Click 'Create API key'.
  5. Copy the API key.
  6. Return to this page.
  7. Click 'Start a New Session' in the header.
  8. Paste the API key in the space given.

Step 2: Set Up Your Session

After you submit your API key, we need some details to create you simulation. You will be redirected to a new screen, where you will need to give the following details:

  1. Choose Your Committee: Which body of the UN will your session take place in?
  2. Set the Agenda: What will the committee discuss?
  3. Set Your Portfolio: Which nation will you represent?
  4. Choose difficulty level: How tough will your competition be?

After you do this, you will have to wait 1-2 minutes while the AI generates the specifics of the simulation.

Step 3: Meet the Chair

Once the AI finsihes generating the simulation, the Chair will open the committee by introducing themselves. At this point you will need to submit your position paper. To learn more about position papers, please refer to the Rules of Procedure page.

After you submit your position paper, you're all set to start!

Step 4: Let the Word Wars Begin!

Start playing. Make speeches, ask questions, raise motions and find solutions to global problems.
